# Broken. open-source reference

Bankers PvP uses the open-source game `Broken.` by Dewan Mukto / dwmk as a design and implementation reference.

Source repository:
`https://github.com/dwmk/RobloxGames`

Source place snapshot:
`BrokenPVPgame_20240713_01.rbxl`

The source repository is distributed under the MIT License, Copyright (c) 2024 Dewan Mukto.

At the current Bankers PvP foundation stage, the combat and movement code under `src/pvp/` is a clean Bankers implementation rather than a verbatim extraction from the binary Broken place. If source scripts, models, UI, or other substantial portions are copied into Bankers later, retain the upstream MIT copyright and permission notice with those portions.
